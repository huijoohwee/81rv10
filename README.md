# 81rv10 · Launch Copilot

Launch Copilot turns one business ask into a source-grounded PRD, TAD, ADR, MVP and GTM proposal
inside Graph's existing workspace. The product entry is [airvio.co/81rv10](https://airvio.co/81rv10/).
`81rv10` owns this product reference; Graph owns its plan, runtime, operations and release.

Use the [Graph runbook][runbook] for current host pairing, native import, Chat commands, review,
reopen/export and publication status. The [canonical product plan][plan], `launch-copilot@0.3.3`,
owns scope, acceptance and evidence. This repository has no independent application server,
importer, parser, graph store, renderer or model proxy.

The five proposal roles share one exact continuity revision. Existing claims require owned-source
evidence; imported reference repositories remain reference-only. NEW work names its owner,
dependencies and future check. Human review checks what the source actually supports.

Graph's existing review/approve/status path binds exact files to OS protected publication.
An exported proposal or merged implementation PR does not prove that an actual proposal was
approved, published and integrated. The runbook separates Dev/component observations from
pending public acceptance, deferred live-model verification, deployment and commercial evidence.

Canvas OS owns shared proposal and ingest/parse contracts. Commerce retains its product and payment
owners. Agentic OS owns lifecycle checks; the protected Graph release owns the generated production
entry and mirror. Product review grants no deployment, payment or outreach authority.

Start with the runbook and its exact accepted dependencies before performing a new walkthrough.
Prices, willingness to pay, collected revenue and repeat use remain unvalidated hypotheses in the plan.
